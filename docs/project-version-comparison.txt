HOW TO READ THIS REPORT
=======================
Project versions come from repository manifests, lockfiles, resolved Gradle graphs,
local executable version commands, and a read-only check of the deployed server.
Latest versions come from official project pages, Google Maven, Maven Central,
npm, PyPI, Google SDK metadata, and official project GitHub repositories.
Preview, alpha, beta, RC, EAP, nightly and snapshot releases are excluded where
the upstream package version or release channel identifies them as such.
For npm, latest means the publisher's latest distribution tag. For Maven, it
means the highest stable-looking version published under the same coordinates.
Changing Maven coordinates, switching a platform variant, or moving to another
framework generation is not treated as an ordinary same-package update.
Published numeric R8 versions do not independently identify the AGP stable channel;
the R8 entry calls out that limitation explicitly.
CURRENT describes version equality, not a security audit or a compatibility guarantee.
NEWER UPSTREAM AVAILABLE does not imply that forcing that version is safe.
OS packages may carry Debian backports without matching upstream version numbers.
Multiple versions of a module can occur in separate build-tool and app classpaths.
Installed tools that are not pinned are labelled as observations, not reproducible pins.
Coverage includes all declared dependencies, all 60 frontend lockfile package entries,
the resolved app/core compile and runtime graphs (including test graphs and BOMs),
the resolved Android build-plugin classpath, major bundled compiler components,
and the development/deployment tools used by this repository. It does not enumerate
every OS package, Python standard-library module, JDK module, or browser internal.
A newer app/CLI version has no independent third-party upstream: these are this
repository's own products. Optional tools with no installed version are identified.
